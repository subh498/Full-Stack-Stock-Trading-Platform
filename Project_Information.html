Zerodha Clone MERN Stack

Full-Stack Stock Trading & Brokerage Ecosystem Overview

1. Executive Project Summary

This project is an end-to-end full-stack clone of Zerodha, India's largest discount stockbroker. It combines a comprehensive marketing website, a dynamic trading console (Kite clone) featuring live-look market watchlists, quick buy/sell execution, portfolio holdings, open positions, funds management, and analytical visualizations.

2. Architecture & Modules

🌐 Frontend (Marketing)

Port: 3000

Tech: React.js, React Router, Bootstrap

Zerodha landing pages: Home, Products, Pricing, Support, About Us, Signup.

📊 Dashboard (Kite Console)

Port: 3001

Tech: React.js, Chart.js, Axios, Context API

Live Watchlist, Buy modal, Orders, Holdings & Positions tracking, Funds margin.

⚙️ Backend Engine

Port: 3002

Tech: Node.js, Express.js, Mongoose

REST API handlers for order management, data models, and database persistence.

🗄️ Database

Engine: MongoDB Atlas

Collections: Holdings, Positions, Orders

Stores stock portfolio records, executed orders, and trading positions.

3. Core Features

  • Watchlist & Market Ticker: Displays real-time stock symbols, daily percentage fluctuations, and quick-action buttons on hover.
  • Interactive Buy/Sell Modal: Enables users to input desired share quantities and limit prices to place instant orders.
  • Holdings Portfolio: Aggregates total stock units, average purchase price, current market valuation, net profit/loss, and portfolio allocation charts.
  • Day Positions Tracking: Distinguishes between intraday (MIS) and overnight delivery (CNC) trades.
  • Funds & Margin Overview: Provides instant breakdown of equity and commodity balances and margin requirements.
  • Data Visualization: Doughnut charts representing asset distributions and vertical bar charts representing portfolio trends.

4. REST API Specifications

Endpoint Method Payload / Response Description
/allHoldings GET Array of Holding Objects Returns list of all active stock holdings and current market prices.
/allPositions GET Array of Position Objects Fetches all active open positions (intraday & delivery).
/allOrders GET Array of Order Objects Retrieves historical and recently placed orders.
/newOrder POST { name, qty, price, mode } Submits and saves a new buy or sell order into MongoDB.

5. Local Setup & Execution Guide

  • Backend: cd backend → npm install → npm start (Runs at http://localhost:3002)
  • Dashboard: cd dashboard → npm install → npm start (Runs at http://localhost:3001)
  • Frontend: cd frontend → npm install → npm start (Runs at http://localhost:3000)
